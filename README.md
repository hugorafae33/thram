# Thram

**Open-source payment infrastructure for AI agents.**

Built for developers. Designed for agents. developed by Goyo.

---

## Overview

Thram is an open-source payment infrastructure project developed by **Goyo**, designed to make financial operations simple, secure, and accessible to AI agents and modern applications.

Our mission is to make integrating payments so effortless that developers and AI agents can focus on building products instead of managing complex financial infrastructure.

Thram aims to provide a unified interface for payment orchestration, spending permissions, human approvals, and bank integrations.

## Features

Thram is currently in early development. Planned capabilities include:

- **Agent-Native Payments:** Payment APIs designed specifically for autonomous AI agents.
- **Simple Integration:** Developer-friendly SDKs and standardized interfaces.
- **Spending Controls:** Configurable permissions, budgets, and transaction limits.
- **Human Approvals:** Secure authorization workflows for sensitive financial operations.
- **Payment Orchestration:** A unified interface for connecting authorized financial providers.
- **Bank Integrations:** Planned support for ACH, FedNow, and RTP through eligible financial partners.
- **Open Infrastructure:** Transparent, extensible, and self-hostable software.

## Architecture

The initial implementation is being designed around:

- TypeScript
- Hono
- PostgreSQL / SQLite
- Drizzle ORM
- Model Context Protocol (MCP)
- REST APIs

Thram is designed to be infrastructure-independent, with support for self-hosting and future managed cloud deployments.

## Development Status

**Status: Early Development**

The first milestone is Thram Core v0.1, a sandbox-based payment orchestration engine.

The initial release will focus on simulated transactions, agent permissions, authorization workflows, and developer integrations.

Live payment processing and banking connectivity will require integrations with authorized financial institutions.
